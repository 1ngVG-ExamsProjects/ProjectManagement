# RASCI Matrix
Prima dell’inizio della fase di esecuzione, il PM redige una [RASCI matrix](#rasci-matrix) per ogni microservizio per mantenere una visione chiara e strutturata delle responsabilità, pur operando in modalità agile con Kanban. Anche se gli sviluppatori scelgono le attività durante l’esecuzione, la matrice consente di avere un quadro di riferimento sempre aggiornato e facilmente consultabile, utile per monitorare ruoli e carichi di lavoro.
