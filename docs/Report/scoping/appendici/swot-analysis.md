# **SWOT analysis**


| Strengths |
| :---- |
| Piattaforma già esistente e funzionante (EcoDomus): base solida da cui possiamo recuperare funzionalità di: Comunicazione con EH: sappiamo gestire le comunicazioni con dispositivi EH Elaborazione dati EH: sappiamo processare i dati inviati dai dispositivi per produrre dati affidabili per realizzare: Contatori Grafici dell’andamento in tempo reali Grafici dei dati storici |


| Weakness |
| :---- |
| Assenza di un’architettura software modulare Funzionalità di previsione dei consumi ancora da definire pienamente: possibile rischio di over-promising o scarsa utilità reale se mal progettate. |


| Opportunities |
| :---- |
| Possibilità di rendere la piattaforma utilizzabile anche in contesti non domestici Possibilità implementare un’architettura scalabile e più manutenibile |


| Threats |
| :---- |
| Resistenza al cambiamento da parte degli studenti: un basso engagement iniziale potrebbe compromettere l'efficacia della piattaforma nel ridurre i consumi RR potrebbe potrebbe limitare la diffusione della piattaforma attraverso una cattiva comunicazione e promozione Problemi tecnici nei sistemi locali installati nelle residenze o nel sistema di autenticazione di RR potrebbero compromettere l’esperienza utente |
