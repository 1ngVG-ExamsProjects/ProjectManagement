# Meetings
- Durante il Daily Status Meeting vengono esaminate le task marcate in giallo nel Stoplight Report, per valutare eventuali criticità da monitorare. Al termine del meeting, il PM aggiorna la Issue Log  e la Scope Bank se necessario.
- I Project Review Meetings sono dedicati alla revisione del Milestone Report, verificando lo stato di avanzamento verso gli obiettivi intermedi.
- I Problem Resolution Meetings: si concentrano invece sulle task segnalate in rosso dal Stoplight Report, affrontando situazioni critiche che richiedono decisioni o interventi immediati.
